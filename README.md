# 九州福岡熊本旅遊網站｜Kyushu Travel Planner 2026

> 一個以 **HTML / CSS / JavaScript + Firebase Realtime Database** 建構的互動式旅遊網站，支援 **景點總覽、即時收藏同步、自訂新增地點、住宿費用、租車資訊、深色 / 淺色模式**。  
> 本版本為目前 **Stable Baseline**，已修復多數 Firebase 同步、收藏與版面問題。

## ✨ 專案亮點

- 🏠 **首頁總覽 (`travel.html`)**：熊本 / 福岡 / 大分 / 別府入口 + 旅遊統計
- 🔎 **景點總覽 (`index.html`)**：搜尋、地區篩選、類別篩選、子類別篩選、排序
- ❤️ **即時收藏同步**：收藏狀態寫入 Firebase `favs/{placeId}`
- ➕ **自訂新增地點**：新增後立即同步到所有使用者畫面
- 💰 **住宿費用分帳**：支援總金額與每人分攤
- 🚗 **租車資訊管理**
- 🌗 **深色 / 淺色模式**
- 📱 **行動裝置優化**
- 🧭 **Google Maps 快速導航**
